# REMIT logo options

All SVG marks use a 1024 × 1024 viewBox and transparent background. Lockups contain an outlined geometric wordmark. App icons are opaque 1024 × 1024 PNGs. Mono SVGs use a white silhouette for themed icons.

1. **Refined grid** — The current four tile mark with larger, softer forms and a balanced gap.
2. **Grid R** — An R monogram with the orange top right tile retained as a brand cue.
3. **Forward grid** — The orange tile becomes a forward arrow to suggest money moving.
4. **Payment stream** — A streamlined R with horizontal payment rails and an orange endpoint.
5. **Approval grid** — The four tile grid carries a check on the orange tile for payroll approval.

**Recommendation:** Concept 2, Grid R. It is distinctive as an app icon while retaining the existing grid and orange accent; Concept 1 is the lowest risk evolution of the current logo.
